# [Spicetify-AutoUpdate](https://nelvismyname.github.io/Spicetify-AutoUpdate)
True non-intrusive Spicetify Auto Updater, barebones and standalone.

> [!NOTE]
> # Spicetify-AutoUpdate is non-intrusive
> Unlike other Spicetify Auto Updaters, this Spicetify Auto Updater is non-intrusive.
>
> What do I mean by non-intrusive? This doesn't send any third party requests to anything but Spicetify only. The scripts contains just the necessary things needed, no useless/dead code included.

# Installment
1. Download the latest [Release](https://github.com/nelvismyname/Spicetify-AutoUpdate/releases), `"Source Code (zip)"`
2. Extract the `zip`
3. Run `Spicetify AutoUpdate.bat`, No need for administrative privileges

And that's it, Spicetify AutoUpdate will automatically update spicetify on startup. `(shell:startup)`

# Building
Spicetify AutoUpdate is barebones, and simple. Code is pretty much common sense
```
git clone https://github.com/nelvismyname/Spicetify-AutoUpdate.git
```
